# Git Flow

Branches:

- `main`: stable delivery branch
- `develop`: integration branch
- `feature/*`: individual features
- `fix/*`: bug fixes
- `release/*`: release preparation

Rules:

1. Every task starts as a GitHub Issue.
2. Every change is made in a branch.
3. Every branch is merged using a Pull Request.
4. Pull Requests must be reviewed by another teammate before merging.
5. Final version will be tagged as `1.0` and published as a GitHub Release.
